# 사슬의 바깥

카뮈의 《이방인》이 다루는 부조리와 사회적 판단에서 출발한 독립 창작 한국어 선택형 서사 게임. 원작의 문장, 인물, 사건을 재현하지 않습니다.

## 실행

Node.js와 Python 3이 있는 환경에서 외부 패키지 설치 없이 실행합니다.

```sh
npm start
```

HTTP 포트는 3000입니다. `npm test`로 전체 576개 선택 경로, 기록 보존, 선택에 따른 서사 변화와 3개 결말을 검증합니다. 정적 호스팅에도 배포할 수 있습니다.

## 플레이

9개 장면, 약 15–25분. 선택은 브라우저의 localStorage에 자동 저장됩니다. 기록 버튼으로 이전 선택의 행정 기록을 읽을 수 있습니다. 마지막 진술로 3개 결말이 갈리며, 앞선 선택들이 증언과 인물들의 후일담을 바꿉니다. 점수나 정답은 표시하지 않습니다. 소리는 기본적으로 꺼져 있으며 버튼으로 잔잔한 합성 지속음을 켤 수 있습니다. 외부 글꼴 요청 없이 시스템 명조체를 사용합니다. 저장소 접근이 차단되면 저장 불가 안내를 표시하며 플레이는 계속됩니다.

## 서사 구조

플레이어는 항구도시의 기록원입니다. 실종자의 배급, 동료의 간병, 안전 보고처럼 양립하기 어려운 필요를 문서로 처리하다 방파제 사고에 대한 심리를 받습니다. 사건의 제도적 원인은 개인 선택 하나로 사라지지 않지만, 선택은 도움의 수혜자, 증거의 신뢰도, 증언과 책임의 범위를 바꿉니다.

마지막 선택은 자기 책임과 공동 책임을 함께 요구하기 / 모든 책임을 떠맡기 / 요구된 진술을 거부하기입니다. 어느 결말도 죽음을 되돌리거나 유족의 삶을 플레이어의 도덕적 보상으로 사용하지 않습니다.

현재 버전은 완결된 첫 플레이어블 초안입니다. Chromium에서 세 경로의 실제 UI 조작과 AI 모의 독자 검토를 수행했습니다. 외부 인간 독자의 플레이테스트와 실제 플레이 시간 측정은 아직 수행하지 않았습니다. 결과와 남은 서사 과제는 [플레이테스트 보고서](playtest/REPORT.md)를 참조하세요.

## 브라우저 회귀 검사

게임 실행 자체에는 외부 패키지가 필요 없습니다. 브라우저 검사에는 개발 의존성이 필요합니다.

```sh
npm ci
# 다른 터미널에서 npm start 실행 후:
npm run test:browser
```

기본 Chromium 경로는 `/usr/bin/chromium`입니다. 다른 설치 경로는 `CHROMIUM_PATH`로 지정하세요. 결과 JSON, 화면 캡처와 실제 화면에서 수집한 경로별 텍스트가 `playtest/`에 저장됩니다. 데스크톱과 두 모바일 화면 크기를 검사하지만 실제 휴대전화 테스트는 아닙니다.

## 서버 없이 실행

`play.html`은 CSS와 게임 코드를 포함한 단일 HTML 파일입니다. 이 파일을 컴퓨터에 저장한 뒤 일반 브라우저에서 여세요. 소스 변경 후 `npm run build:standalone`으로 다시 생성합니다. 브라우저의 로컬 파일 저장 정책에 따라 이어하기 저장이 제한될 수 있으며, 저장 실패 시 게임에 안내가 표시됩니다.

클라우드의 `localhost:3000`은 사용자 컴퓨터의 주소가 아닙니다. 현재 클라우드 온보딩 UI에는 해당 서버를 연결하는 웹 미리보기 기능이 없습니다.

단일 파일의 세 결말과 새로고침·이어하기는 Chromium에서 HTTP로 검증했고, HTML 외의 리소스 요청이 없음을 확인했습니다. 이 관리 환경은 `file://` 접근을 브라우저 정책으로 차단하므로 로컬 파일 직접 열기는 여기서 검증하지 못했습니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`은 `main`에 push할 때 전체 서사 검사를 실행하고 `dist/`만 GitHub Pages에 배포합니다. 빌드는 외부 패키지 없이 Node.js 24에서 실행됩니다. 테스트 기록, 스크린샷, 개발 의존성은 사이트 배포물에 들어가지 않습니다.

처음 한 번 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택해야 합니다. 이어서 **Actions → Deploy game to GitHub Pages → Run workflow**를 실행하세요. 이후 main 변경은 자동으로 배포됩니다.

기본 배포 주소는 `https://dhkddls.github.io/stranger/`입니다. Actions 배포 성공 전에는 주소가 작동하지 않을 수 있습니다. 로컬 검증은 `npm test`와 `npm run build:pages`로 수행합니다.
